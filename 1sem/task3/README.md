# task3 — Word and Special Token Processor

Программа `task3` анализирует входной поток (обычно stdin), разделяет его на **слова** и **специальные токены**, затем выполняет следующие действия:
- Выводит исходный список токенов
- Сортирует список лексикографически
- Подсчитывает общее количество символов в «обычных» словах (исключая специальные токены)
- Находит и выводит **самый редко встречающийся символ** среди всех «обычных» слов

Обработка завершается по достижению конца ввода (`EOF`) или при получении пустой строки (в зависимости от режима ввода).

## 🔧 Сборка

Проект собирается с помощью `make`.
