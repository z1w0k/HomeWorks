# Клиент-серверное приложение с инкрементом

Многопроцессное клиент-серверное приложение на C, где сервер обрабатывает каждого клиента в отдельном процессе. Клиент отправляет числа, сервер прибавляет к ним текущее значение инкремента и возвращает результат.

### Компоненты:
- **`server.c`** - многопроцессный сервер
- **`client.c`** - клиент для подключения к серверу
- **`common.h`** - общие заголовки и определения
- **`Makefile`** - автоматизация сборки

## 🎮 Команды

| Команда | Описание | Пример | Ответ |
|---------|----------|--------|-------|
| `N` | Число: прибавляет increment | `5` | `6` (если increment=1) |
| `+N` | Установить новое значение increment | `+10` | `Ok` |
| `\?` | Показать текущий increment | `\?` | `5` |
| `\-` | Отключиться от сервера | `\-` | `Bye` |

**Важно:**
- Начальное значение increment = **1** для каждого нового клиента
- Команды регистрозависимы
- `\-` и `\?` - используется обратный слэш (`\`), не прямой (`/`)

## 🔧 Сборка

### Исправленный Makefile:
```makefile
CC = gcc
CFLAGS = -Wall -Wextra -O0 -g
all: server client

server: server.c common.h
	$(CC) $(CFLAGS) -o server server.c

client: client.c common.h
	$(CC) $(CFLAGS) -o client client.c

clean:
	rm -f server client *.o

.PHONY: all clean
