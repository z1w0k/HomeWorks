# Ориентированный граф (Directed Graph)

## Описание проекта

Реализация абстрактного типа данных (АТД) "Ориентированный граф" на языке C++. Проект выполнен в рамках учебного задания и демонстрирует основные принципы объектно-ориентированного программирования: инкапсуляцию, наследование, полиморфизм, а также работу с динамической памятью и обработку исключений.

Граф хранит вершины (целые числа) и направленные ребра с текстовыми метками. Внутреннее устройство скрыто от пользователя, работа с графом осуществляется через публичный интерфейс.
