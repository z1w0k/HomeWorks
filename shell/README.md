# MyShell - Полноценный интерпретатор команд

## Возможности

✅ **Токенизация:**
- Поддержка пробелов, табуляций
- Кавычки (одинарные и двойные)
- Экранирование символов (\)
- Комментарии (#)
- Переменные: $HOME, $SHELL, $USER, $EUID

✅ **Специальные символы:**
- Пайпы: `|`
- Перенаправления: `<`, `>`, `>>`
- Логические операторы: `&&`, `||`
- Последовательное выполнение: `;`
- Фоновый режим: `&`

✅ **Встроенные команды:**
- `cd` - смена директории
- `pwd` - текущая директория
- `echo` - вывод аргументов
- `exit` - выход из shell

✅ **Дополнительные функции:**
- Обработка сигналов (SIGINT, SIGCHLD)
- Фоновое выполнение команд
- Динамическое управление памятью
- Расширение переменных окружения
