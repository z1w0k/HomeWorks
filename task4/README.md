# Мини-утилиты командной строки на C

Этот проект представляет собой набор упрощённых реализаций стандартных Unix-утилит, написанных на языке программирования C с использованием низкоуровневых системных вызовов POSIX (таких как `open`, `read`, `write`, `stat`, `lstat`, `readdir`, `rename`, `getcwd` и др.). Цель проекта — продемонстрировать понимание работы с файловой системой, аргументами командной строки и базовыми концепциями операционных систем.

---

## 📁 Содержимое проекта

| Файл     | Утилита | Назначение |
|----------|---------|------------|
| `cat.c`  | `cat`   | Вывод содержимого одного или нескольких файлов на стандартный вывод. Поддерживает флаг `-n` для нумерации строк. |
| `cmp.c`  | `cmp`   | Посимвольное сравнение двух файлов. Выводит позицию первого различия (номер строки и символа) или сообщает об идентичности. |
| `echo.c` | `echo`  | Вывод переданных аргументов через пробел. Поддерживает флаг `-n` для подавления завершающего символа новой строки. |
| `ls.c`   | `ls`    | Отображение содержимого директории. Поддерживает флаги `-l` (подробный вывод), `-G` (скрыть группу), `-R` (рекурсивный обход). |
| `mv.c`   | `mv`    | Переименование или перемещение файла/директории с использованием системного вызова `rename()`. |
| `pwd.c`  | `pwd`   | Вывод абсолютного пути текущей рабочей директории. |

---

## ⚙️ Сборка

Проект поставляется с простым `Makefile` для автоматической сборки.

### Требования
- Установленный компилятор `gcc`
- Стандартная библиотека C (`glibc` или аналог)
- POSIX-совместимая ОС (Linux, macOS и др.)
