## 🎯 Описание задачи

**Условие:**  
Пять философов проводят время, чередуя размышления и приёмы пищи. Они сидят за круглым столом, перед каждым философом стоит тарелка со спагетти. Для еды каждому философу нужны **две вилки**, но на столе всего **пять вилок** (по одной между каждыми двумя соседями).

**Проблема:**  
Если все философы одновременно возьмут левую вилку, то правой вилки ни у кого не окажется — возникает **deadlock** (взаимная блокировка).

**Задача:**  
Создать алгоритм, который позволяет философам есть, избегая deadlock и обеспечивая честное распределение ресурсов.

## 💡 Решение

Программа использует **IPC семафоры System V** для синхронизации доступа к вилкам:
- Каждой вилке соответствует один семафор
- Значение семафора: `1` = вилка свободна, `0` = вилка занята
- Философ должен захватить оба семафора (левую и правую вилку) перед едой

## 🏗️ Архитектура

### Основные компоненты:

```c
// Создание и управление семафорами
int semget(key_t key, int nsems, int semflg);
int semctl(int semid, int semnum, int cmd, ...);
int semop(int semid, struct sembuf *sops, unsigned nsops);

// Процесс-философ
void philosopher(int i, int semid) {
    while (!stop) {
        think();           // Думает случайное время
        take_forks(i);     // Пытается взять вилки
        eat();             // Ест случайное время
        put_forks(i);      // Кладет вилки
    }
}
